# Routine Data Quality Assessment (RDQA) Dashboard 
## Overview
This project is an automated RDQA dashboard developed in Excel to support routine monitoring, data validation, and M&E system assessment within health programs.

## Features
- Automated KPI Cards
- Data Validation Assessment
- M&E System Assessment
- Register vs Summary vs DHIS2 Comparison
- Radar Chart for Data Quality Dimensions
- Interactive Dashboard Filters

## Data Quality Dimensions Assessed
- Accuracy
- Completeness
- Timeliness
- Integrity
- Precision
- Confidentiality

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Automated Formulas

## Purpose
The dashboard was designed to simulate quarterly RDQA activities conducted across PHCs and Health Clinics to identify reporting discrepancies and strengthen data quality systems.
